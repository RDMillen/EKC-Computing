# EKC Computing Resources
This repository acts as a central storage for content relating to courses taught at EKC Ashford. 

Here you will find resources relating to:
* Gateway Level 2 Diploma in Digital and IT Skills
* Pearson Edexcel T-Level in Digital Software Development
* Miscellaneous computing-related oneshot sessions

Each resource is provided in multiple formats for use in various softwares.

* A standard MS PowerPoint/LibreOffice Impress `.pptx` file.
* A [Kova](https://kova.md) compatible MarkDown file.
* A HTML file with a self-contained version of the presentation.
* A PDF version of the presentation, with one slide per page.
