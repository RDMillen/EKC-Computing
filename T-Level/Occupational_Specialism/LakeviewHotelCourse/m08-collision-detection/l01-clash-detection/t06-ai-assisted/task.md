# Using generative AI for short code snippets

The assessment expects you to use a generative AI model for short code snippets, and to critically review
what it gives you. You are not asked to hand it the whole solution. This task is practice for that habit.

## Task
1. Ask an AI tool for a function that checks whether a date range overlaps any range in a list of existing ranges
   (without telling it the rule you learned in this module).
2. Review its answer critically:
   - does it treat back-to-back stays correctly (`<` / `>` rather than `<=` / `>=`)?
   - does it handle a range that surrounds another?
   - is it safe (no SQL built with f-strings)?
3. Test it with every timeline in the chart from task 8.1.1.
4. Keep, change or reject it. If you keep any of it, adapt it to your own naming and style.
5. Record everything in `AI_LOG.md`.

> Code you have not reviewed may contain bugs or security holes you are not aware of. Logging, testing and
> improving a snippet shows good practice, and it is the evidence the assessment looks for.
> This table is for practice. In the assessment you must use Pearson's official AI Log template, which your
> teacher will give you. The columns are similar, so the habit carries over.
